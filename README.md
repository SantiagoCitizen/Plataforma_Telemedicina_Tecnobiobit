# Plataforma_Telemedicina_Tecnobiobit

 * Estado del proyecto
Actualmente el proyecto se encuentra en desarrollo.
 * Frontend implementado (HTML, CSS)
 * Diseño de base de datos completo
 * Backend en proceso de desarrollo

Se planea integrar lógica de servidor para la gestión de usuarios y consultas médicas en futuras versiones.

* Proyecto enfocado en brindar consultas médicas en línea para comunidades rurales, facilitando el acceso a servicios de salud mediante una plataforma web.
Tecnologías utilizadas hasta el momento
 * HTML
 * CSS
 * MySQL

* Diseño de Base de datos

Entidades principales
 * Administrador: Gestión del sistema y control de información
 * Paciente: Registro de usuarios que solicitan consultas médicas
 * Médico: Profesionales encargados de brindar atención
 * Cita: Registro y control de consultas médicas

Relaciones
 * Un paciente puede tener múltiples citas
 * Un médico puede atender múltiples citas
 * Las citas están asociadas a pacientes y médicos mediante claves foráneas

* Funcionalidades soportadas por la base de datos
 * Gestión de usuarios (administradores, pacientes, médicos)
 * Programación de citas médicas
 * Control de estado de citas (Agendada, Pendiente, Realizada, Cancelada)
 * Registro de métodos de consulta (Videollamada, Chat en línea)

El archivo SQL completo se encuentra en la carpeta /Database.
